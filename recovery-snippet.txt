HOW TO GET THE CLINIC'S EXISTING RECORDS OFF A COMPUTER
=======================================================

Do this on the computer and in the browser the clinic actually used to
enter patients. Nothing is uploaded anywhere; you just copy text out.

IMPORTANT: browser storage is kept separately for every web address
(origin). The clinic app has lived on three addresses, and each one kept
its own copy:

  1. https://clinic-ochre-seven.vercel.app      (key: patients)
  2. https://site-90530542d24f4a0a8f220f83ab1afa1d.freebuff.page
                                                (key: vitalis_cache_v2)
  3. https://patient.129.154.239.74.sslip.io    (server-side; see note)

Run STEP 3 once on EACH address in that browser, and save a separate
file from each. Then restore all the files into the fixed page. They
merge; nothing is overwritten.

STEP 1 - Open one clinic link in that browser
---------------------------------------------
Use the exact same address that was used before. Start with
https://clinic-ochre-seven.vercel.app
Then repeat with the freebuff.page address above.

STEP 2 - Open the browser console
---------------------------------
Windows / Linux:  press F12, then click the "Console" tab
                  (or Ctrl + Shift + J)
Mac:              Cmd + Option + J

STEP 3 - Paste this and press Enter
-----------------------------------
copy(JSON.stringify((() => {
  const read = k => { try { return JSON.parse(localStorage.getItem(k)); } catch (e) { return null; } };
  const out = new Map();
  const add = p => {
    if (!p || typeof p !== 'object') return;
    const row = Object.assign({}, p.meta || {}, p);
    if (!row.reg && row.id != null && !/^\d+$/.test(String(row.id).trim())) row.reg = String(row.id).trim();
    if (!(row.name || row.phone || row.reg)) return;
    const k = String(row.reg || '').toLowerCase().replace(/[^a-z0-9]/g, '')
           || String(row.phone || '').replace(/\D/g, '')
           || String(row.name || '').toLowerCase();
    if (!out.has(k)) out.set(k, row);
  };
  const legacy = read('patients');
  if (Array.isArray(legacy)) legacy.forEach(add);
  const state = read('clinic_state_v2');
  if (state && Array.isArray(state.rows)) state.rows.forEach(add);
  const backup = read('patients_backup_v1');
  if (Array.isArray(backup)) backup.forEach(add);
  const cache = read('vitalis_cache_v2');
  const cacheRows = Array.isArray(cache) ? cache : (cache && Array.isArray(cache.patients) ? cache.patients : []);
  const notes = read('vitalis_notes_v1') || (cache && cache.notes) || {};
  cacheRows.forEach(p => {
    const r = Object.assign({}, p);
    if (notes[r.id] && !r.notes) r.notes = notes[r.id];
    add(r);
  });
  return { origin: location.origin, takenAt: new Date().toISOString(), patients: Array.from(out.values()) };
})(), null, 2))

If `copy` is not defined in that browser, run the same thing without the
`copy(...)` wrapper and copy the printed text by hand.

OPTIONAL - if the page shows 0 records but the clinic used this browser
-----------------------------------------------------------------------
The fixed page also keeps a second copy in IndexedDB. Paste this to read
it (it prints the result; copy it by hand if needed):

indexedDB.open('clinic-directory', 1).onsuccess = e => {
  const db = e.target.result;
  const req = db.transaction('kv', 'readonly').objectStore('kv').get('state');
  req.onsuccess = () => console.log(JSON.stringify(req.result, null, 2));
};

STEP 4 - Save it
----------------
Paste into Notepad (or any text editor) and save as, for example
    patients-vercel.json
    patients-freebuff.json

STEP 5 - Load it into the fixed page
------------------------------------
Open the new Patient Directory page, press "Restore", and choose the
file(s). It merges; it never overwrites or deletes anything. Check the
number in the green pill afterwards.

If STEP 3 gives an empty "patients" list on every address in every
browser, then the records are not in that browser at all. The only
remaining server-side source is the Cloudflare D1 database behind the
freebuff.page site, which requires signing in there with the clinic's
own Freebuff account (the doctor's login), then adding the records once
and using "Backup" to export them.


WHERE THE DATA ACTUALLY WENT (summary)
--------------------------------------
- The Vercel app stored records in browser localStorage under `patients`
  until commit 60c7f4a ("Connect patient directory to Supabase").
- That commit deleted the localStorage read/write code and pointed the
  page at https://oqarvapuiiqfjemqubfh.supabase.co . That host never
  existed (NXDOMAIN, no DNS history, no certificate ever issued), so any
  patient added after that commit was sent to a black hole and lost.
- Records added BEFORE that commit are still sitting in the browser's
  `patients` key. The old code never deleted them on upgrade, it just
  stopped reading them. The fixed page reads and migrates them now.
- The freebuff.page deployment kept its own mirror in `vitalis_cache_v2`
  and synced to a Cloudflare D1 database behind Freebuff sign-in. Extra
  patients added there are in that key and/or that D1 database.
- The Oracle VM deployment (patient.129.154.239.74.sslip.io) has its own
  SQLite file with 31 patients and 30 clinical notes, all reachable via
  its API. It is the source of the built-in registry in the fixed page.
