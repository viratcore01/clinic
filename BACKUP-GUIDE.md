# Patient Directory — Simple Backup Guide

## 1. Can I keep adding patients?

**Yes.** Every patient you add is saved on your computer immediately. You do not need the internet for it.

But right now there is **only one copy: on this computer**. If this computer is lost, reset, or the
browser's data is cleared, the records are gone. So the one habit that protects you is the backup
below.

## 2. How to take a backup (1 minute)

1. Open the Patient Directory in the **same browser** you always use (Chrome, Edge or Brave).
2. Click the **Backup** button at the top.
3. Click the big **Download backup now** button.
4. A file appears in your **Downloads** folder, named like
   `patients-backup-2026-11-23_1830.json`.
5. Move that file to a safe place (see step 4).

The page will say **“Backup verified: 32 records downloaded”**. If it says the check failed, nothing
was downloaded — try again before adding more patients.

## 3. How often?

- **Every Friday** — one backup a week is the minimum.
- **Also** after a busy day when you added many patients.
- **Also** before you update Windows, change computers, or let anyone repair the machine.

The page reminds you if there has been no backup for 7 days.

## 4. Where should I keep the file?

Keep **three copies in two places**:

1. On the computer, in a folder called `Clinic Backups` (not in Downloads).
2. In your **Google Drive** or **OneDrive** — upload the file.
3. Email the file to yourself once a month.

Never send the file on a public WhatsApp group. It contains patient names and phone numbers. Send it
only to yourself or to the clinic owner.

## 5. If records disappear — how to restore

1. Open the **same Patient Directory link** in the **same browser**.
2. Click **Restore**.
3. Choose the newest `patients-backup-….json` file.
4. The page says **“Restored … (N new). Nothing was overwritten.”**
5. Check the green count at the top matches what you expect.

Restore only **adds** records. It never deletes and never overwrites, so it is safe to use even if you
are unsure.

There is also a second, automatic copy:

1. Click **Backup**.
2. Under **Automatic copies on this device** you will see a list with dates.
3. Press **Restore** next to the date you want, or **Download** to save that copy as a file.

## 6. Things that will destroy the records — please avoid

- **Do not** click “Clear browsing data”, “Clear site data”, or “Delete cookies and site data”.
- **Do not** use a **Private / Incognito** window for patient entry. Everything is erased when it closes.
- **Do not** use a different browser or a different computer and expect the records to be there.
  They are stored per browser and per device; carry a backup file instead.
- **Do not** rename the website address. Records are tied to that exact address.

## 7. What the colours mean

- **✓ saved on this device · 31 records** — all good.
- **⚠ not saved — backup now** — the browser is blocking storage. Press **Backup** immediately and
  contact the clinic owner. Do not keep typing.
- **backup: server not set up** — there is no automatic server copy yet. The downloaded file is your
  only protection.
